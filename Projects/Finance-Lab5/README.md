# Predicting Credit Scores with Machine Learning

This project uses financial statement data to predict firms’ credit scores using machine learning. The objective is to replicate a bank’s credit screening process and evaluate how AI models can match or improve upon human loan officers’ decisions.

## Key Tasks

- Cleaning and analyzing balance sheet and income statement data

- Engineering financial ratios and firm-level features

- Performing feature selection and importance analysis

- Training models (e.g., Random Forest, XGBoost) to predict credit scores

- Evaluating accuracy with the True Positive Ratio and analyzing misclassifications

## Methodology

- Data Preparation — Import, clean, and enhance firm-level financial data.

- Model Training — Fit and tune supervised ML models to classify credit scores.

- Evaluation — Compare models’ predictive accuracy and fairness impacts and suggest new evaluation metric.
